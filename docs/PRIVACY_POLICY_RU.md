# Privacy policy (RU) — Автожурнал

**Приложение:** Автожурнал  
**Пакет Android:** `com.calculatorplatform.autojournal`  
**Оператор:** ForestMusic  
**Версия документа:** 1.0 (v1 release)

## Кратко

Приложение — локальный автомобильный журнал (заправки, расходы, ТО, статистика).
Данные хранятся на устройстве в SQLite. Подключены Yandex AppMetrica и Yandex
Mobile Ads (баннеры на Главной и Статистике; редкий interstitial при открытии
Статистики по политике частоты).

Мы **не** утверждаем, что «данные не собираются» — аналитика и реклама
обрабатывают технические события и идентификаторы согласно политикам Яндекса.

Публичный HTML размещается по HTTPS до модерации RuStore (см. `docs/privacy.html`).

## Какие данные обрабатываются

**На устройстве (не отправляются на сервер ForestMusic как содержимое журнала):**

- автомобили, заправки, расходы, записи обслуживания, заметки пользователя;
- резервные копии JSON и CSV-экспорты, созданные по запросу пользователя;
- локальные напоминания по датам обслуживания.

**Через SDK (Яндекс / рекламная сеть):**

- категориальные события аналитики (действия в приложении без персональных
  полей: без заметок, имён автомобилей, пробега, сумм, путей к файлам);
- рекламные идентификаторы и телеметрия SDK согласно политикам Яндекса.

Приложение **не** требует аккаунта и **не** синхронизирует журнал в облако.

## Цели обработки

- вести учёт расходов и расхода топлива на устройстве;
- резервное копирование и восстановление по инициативе пользователя;
- экспорт CSV и текстового отчёта через системный Share Sheet;
- локальные напоминания об обслуживании (с разрешения пользователя);
- улучшение продукта по агрегированной аналитике;
- показ рекламы (баннеры + ограниченный interstitial).

## Резервные копии и Share

JSON backup, CSV и текстовый отчёт формируются на устройстве. Пользователь сам
выбирает, куда сохранить или отправить файл, через системные диалоги Android.

## Разрешения Android

- **Уведомления** — только для напоминаний об обслуживании (можно отключить).
- **Доступ к файлам** — только через системный Document Picker при восстановлении
  из резервной копии; приложение не запрашивает широкий доступ к хранилищу.

## Контакты

Обращения по конфиденциальности — через контакт оператора ForestMusic
(указать email или форму до публикации URL).

Полный юридический текст можно расширить по шаблону ForestMusic Foundation
перед публикацией URL в RuStore.
