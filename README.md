# Автожурнал (Auto Journal)

Local-first автомобильный журнал для Android / RuStore.

**Current:** Phase 2 — vehicles + fuel entry UI

## Stack

- Expo SDK 57 + React Native + TypeScript
- Expo Router
- expo-sqlite (schema migrations)
- Jest unit tests for domain math

## Scripts

```bash
npm install
npm test
npm start
npm run android
```
